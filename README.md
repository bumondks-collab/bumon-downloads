# BUMON — downloads

Ficheiros públicos de instalação dos produtos BUMON / OMS ENT.

## BUMON CENTRAL

Gere as licenças e instala os plugins BUMON comprados em [onlinemusicstrategy.com](https://onlinemusicstrategy.com).

**[Descarregar a BUMON CENTRAL para Windows](https://github.com/bumondks-collab/bumon-downloads/releases/latest/download/BUMON-CENTRAL-Setup.exe)** (Windows 10/11, 64 bits)

1. Instala e abre a BUMON CENTRAL.
2. Clica em **Entrar com OMS** e faz login com a tua conta do site no navegador.
3. Em **Os meus produtos**, ativa e instala os plugins que compraste.

O instalador ainda não tem assinatura digital, por isso o Windows pode mostrar "O Windows protegeu o computador".
Clica em **Mais informações → Executar mesmo assim**. O SHA-256 de cada ficheiro está em `SHA256SUMS.txt`, na
página de cada release.

## Plugins

Os zips dos plugins são instalados pela BUMON CENTRAL. Sem uma licença ativa, os plugins ficam em bypass e o áudio
passa sem alterações.
